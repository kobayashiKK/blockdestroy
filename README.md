# DOPAMINE BREAKER 🧱💥

ドーパミンがドバドバ出るブロック崩し。ブラウザだけで動作、PC・スマホ両対応。

## 遊び方

`index.html` をブラウザで開くだけ。（[GitHub Pages](https://kobayashikk.github.io/blockdestroy/) でも遊べます）

- **PC**: マウスでパドル移動 / `←` `→`（or `A` `D`）/ クリック・スペースで発射
- **スマホ**: 指でスライドしてパドル移動 / タップで発射

## ドーパミン要素 🔥

- 連続ヒットで **コンボ倍率** がぐんぐん上昇、スコアも音程も上がっていく
- ブロック破壊で **パーティクル爆発**・**画面シェイク**・**フラッシュ**
- ランダムで降ってくる **パワーアップ**（ワイド / マルチボール✦ / ファイアボール🔥 / 貫通⚡ / スロー🐢 / キャッチ🎯）
  - **マルチボール**: ボールが一気に3倍に増殖
  - **貫通**: ボールがブロックを貫通して突き進む（ファイアボールも貫通する）
- レベルが上がるごとにブロックが増えてどんどん激しく
- Web Audio による効果音、ハイスコアはブラウザに保存

## 脱衣ブロック崩し風の癒し演出 🐾

- 各レベルのブロックには **普通の表情の動物の顔** が描かれている
- ブロックを崩していくと、その下から **笑顔の動物** が少しずつ現れる
- 全部崩すと笑顔の全身がドーンと登場（癒し）
- 動物は全部 canvas で手描き（ねこ / いぬ / うさぎ / くま / ぱんだ / かえる / ぶた / ひよこ）

## その他の機能

- **一時停止**: 画面左下の ⏸ ボタン、または `P` / `Esc` キー
- **キャッチ＆狙い撃ち** 🎯: パワーアップ取得後、ボールがバーにくっつく。
  ねらいの矢印が左右に振れるので、好きな方向でタップ / クリック / `Space` を押して一度だけ発射

技術: 依存なしの単一HTML（Canvas 2D + Web Audio API）。
